## Reflection

During this assignment, I learned how a client-server application works using C and network programming. I learned how to create TCP sockets using `socket()`, `bind()`, `listen()`, `accept()` and `connect()`. I also learned the difference between TCP and UDP. TCP was used for reliable communication between the Controller and Agent, while UDP was used for periodic monitoring messages. Another important thing I learned was how to design and follow a fixed communication protocol. Commands such as `AUTH`, `SYSINFO`, `LISTPROC`, `EXEC`, `PUT`, `GET`, `MONITOR START`, `MONITOR STOP` and `QUIT` had to follow the required format and include my personalised SID.

One of the main challenges was understanding that TCP is a byte stream. A single `recv()` call may receive only part of a command, or it may contain several commands together. Because of this, I implemented a line-buffering method to correctly detect newline-terminated commands. File transfer was another difficult part. For `PUT` and `GET`, the program had to transfer exactly the specified number of bytes. I also had to make sure that bytes already stored in the TCP buffer were not lost when receiving a file. UDP monitoring was challenging because it required a separate UDP socket while the TCP connection remained active. I also learned how to support multiple Controllers by using `fork()`, where the parent Agent continues accepting connections and each child process handles one Controller.

I used AI assistance during the assignment to understand networking concepts, plan the implementation, explain compiler or runtime errors, and review sections of code. AI also helped me structure testing steps and documentation. However, I compiled and tested the program myself on Linux and checked the actual outputs before using them as evidence. When something did not work, I compared the result with the expected protocol and corrected the implementation. This helped me understand the code instead of only copying it.

If I improved this project further, I would make the Controller interface more user-friendly and add more input validation. I would also separate some large functions into smaller modules to make the program easier to maintain. Another improvement would be to create automated tests for authentication, file transfers, monitoring, and multiple simultaneous Controllers. Overall, this assignment improved my understanding of TCP/IP networking, C socket programming, concurrency, protocol handling, file transfer, logging, and error handling.
